# Roadmap

השלבים מסודרים לפי תלות ותוצר; אין התחייבות ללוח זמנים לפני הערכת העבודה ובחירת ספק.

| שלב | תוצר | תנאי השלמה |
| --- | --- | --- |
| 0 — תשתית | פרויקט ChatGPT, מאגר פיתוח ומסמכי יסוד | קישורים ותוכן מאומתים בשני המקומות; מצב חיבור Codex מתועד |
| 1 — אבטיפוס | מסכים, הגרלה ומשחקים עם נתוני דמה | זרימה מלאה בעברית ובאנגלית, כולל empty/error ונגישות |
| 2 — פיילוט חי | ספק אחד באזור ניסוי | הרשאה, כיסוי, תקציב ובדיקות פתיחה מאומתים; הפרדה מדמה |
| 3 — השקה מוגבלת | פריסה, ניטור ומשוב | בדיקות קבלה, בקרה על הוצאות, פרטיות והחלטת השקה |
| 4 — משחק משותף | קישור הזמנה, חדר זמני והחלטה קבוצתית | פקיעה, יציאה, סנכרון והגבלת שימוש נבדקו |
| 5 — הרחבה | אזורים ושפות נוספים, שותפי הזמנה | כיסוי ותנאים נבדקים לכל שוק; חיבור Wolt/תן ביס רק אם אושר |

הפעולה הבאה לפיתוח היא MUN-001: יצירת שלד מקומי עם ספק דמה. הפעולה הבאה למוצר היא בחירת אזור ניסוי ותקציב ספק; הן יכולות להתקדם במקביל בלי לחבר שירות בתשלום.
