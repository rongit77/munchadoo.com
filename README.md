# Munchadoo

אפליקציה משחקית גלובלית שעוזרת להחליט איפה אוכלים — ולהעביר יחד את ההמתנה לאוכל.

הדומיין **munchadoo.com** נרכש. הכיוון: מותג צעיר וצבעוני, קמע מקורי וחוויית משחק למשפחות, זוגות, חברים ועובדים.

## מצב הפרויקט

שלב: אבטיפוס Web עובד מקומית. כולל עברית ואנגלית, סינון והגרלת מסעדות דמה ושני משחקי המתנה. אין חיבור לספק מסעדות או אינטגרציית משלוחים פעילה. פרטי ההקמה המאומתים מופיעים ב־[SETUP](docs/SETUP.md).

מאגר הפיתוח: [rongit77/munchadoo.com](https://github.com/rongit77/munchadoo.com).

פתחו תיקייה זו כפרויקט מקומי ב־Codex. קראו את AGENTS.md ואת משימות MUN-001 עד MUN-003 לפני הקמת האפליקציה. הקוד והתיעוד כאן הם מקור האמת המנוהל בגרסאות; החלטות מוצר משיחות ChatGPT מועתקות למסמכים לפני מימוש.

## הרצה מקומית

נדרש Node.js 24 (מומלץ) או 22.13 ומעלה בענף 22. אין להשתמש ב־Node 23 שאינו נתמך בכלי הבדיקות.

```sh
npm ci
npm run dev
```

פתחו http://127.0.0.1:3000. התצוגה פועלת במחשב המקומי בלבד. לא נדרשים מפתחות API.

```sh
npm run lint
npm run typecheck
npm test
npm run build
npm start
```

`npm start` מריץ בניית production קיימת. `npm run format` מעצב את הקוד. CI מוגדר להרצת lint, typecheck, בדיקות יחידה ו־build בכל push ו־pull request.

## מה עובד באבטיפוס

- בחירת אזור מתוך רשימה או בקשת מיקום מפורשת, רדיוס 1–20 ק״מ ומסנן מטבח.
- נתוני דמה קבועים באזור תל אביב, מצבי פתוח/סגור/לא ידוע, מרחק בקו אווירי ומצב ללא תוצאות.
- הגרלה מתוך מקומות פתוחים, בדיקת סטטוס דרך המתאם לפני תוצאה, ללא חזרה מיידית כשיש חלופה, ודילוג על הנפשה.
- שני משחקי 5 סיבובים באותו מכשיר: ״מה הייתם בוחרים?״ ו״נחשו את המאכל״. ארבעה קהלים ושתי שפות.
- קמע ואיורי אוכל מקוריים בקוד SVG, RTL/LTR, חלון תוצאה עם מלכודת מיקוד מובנית ו־reduced motion.

## גבולות הגרסה

בחירת האזור ידנית היא מתוך רשימת אזורי דמו, ללא geocoding של כתובת חופשית. מיקום המכשיר אינו נשמר ואינו נשלח לספק. אזור ללא נתוני דמה מחזיר תוצאות ריקות. אין ניווט למקומות הבדיוניים או קישורי הזמנה פעילים. זמני פתיחה הם סטטוסים מדומים ולא חישוב שעות אמיתיות; בדיקות חצות ושעון קיץ יתווספו עם ספק חי. האתר משתמש בגופני Google עם חלופות מקומיות.

תוצאות בדיקה ומגבלות מפורטות ב־[VALIDATION](docs/VALIDATION.md). אין לבחור רישיון קוד פתוח או להפעיל שירות בתשלום בלי החלטת בעל הפרויקט.
