# Munchadoo

אפליקציה משחקית גלובלית שעוזרת להחליט איפה אוכלים — ולהעביר יחד את ההמתנה לאוכל.

הדומיין **munchadoo.com** נרכש. הכיוון: מותג צעיר וצבעוני, קמע מקורי וחוויית משחק למשפחות, זוגות, חברים ועובדים.

## מצב הפרויקט

שלב: אבטיפוס Web עובד מקומית. כולל עברית ואנגלית, סינון והגרלת מסעדות ושני משחקי המתנה. חיבור Google Places זמין עם מפתח שרת מקומי. אין אינטגרציית משלוחים פעילה. פרטי ההקמה המאומתים מופיעים ב־[SETUP](docs/SETUP.md).

מאגר הפיתוח: [rongit77/munchadoo.com](https://github.com/rongit77/munchadoo.com).

## הרצה מקומית

נדרש Node.js 24 (מומלץ) או 22.13 ומעלה בענף 22. אין להשתמש ב־Node 23 שאינו נתמך בכלי הבדיקות.

```sh
npm ci
npm run dev
```

פתחו http://127.0.0.1:3000. התצוגה פועלת במחשב המקומי בלבד. לחיפוש חי יש להעתיק את `.env.example` אל `.env.local` ולהגדיר `GOOGLE_PLACES_API_KEY`. אין לשתף או להעלות את הקובץ. ללא מפתח תוצג שגיאה; אין מעבר סמוי לנתוני דמה.

```sh
npm run lint
npm run typecheck
npm test
npm run build
npm start
```

`npm start` מריץ בניית production קיימת. `npm run format` מעצב את הקוד. CI מוגדר להרצת lint, typecheck, בדיקות יחידה ו־build בכל push ו־pull request.

## מה עובד באבטיפוס

- בחירת אזור מתוך רשימה או בקשת מיקום מפורשת, רדיוס 1–20 ק״מ ומסנן מטבח.
- נתוני Google Places לפי אזור או מיקום, סטטוס פתיחה, מרחק בקו אווירי ומצב ללא תוצאות. נתוני דמה נשמרו לבדיקות בלבד.
- הגרלה מתוך מקומות פתוחים, בדיקת סטטוס דרך המתאם לפני תוצאה, ללא חזרה מיידית כשיש חלופה, ודילוג על הנפשה.
- שני משחקי 5 סיבובים באותו מכשיר: ״מה הייתם בוחרים?״ ו״נחשו את המאכל״. ארבעה קהלים ושתי שפות.
- קמע ואיורי אוכל מקוריים בקוד SVG, RTL/LTR, חלון תוצאה עם מלכודת מיקוד מובנית ו־reduced motion.

## גבולות הגרסה

בחירת האזור ידנית היא מתוך רשימת ערים, ללא geocoding של כתובת חופשית. מיקום החיפוש נשלח לשרת ול־Google בבקשת POST, ואינו נרשם בלוגים של האפליקציה. יש קישורים למפות Google; אין קישורי הזמנה פעילים. סטטוס פתיחה מתקבל מ־Google; בדיקות חצות ושעון קיץ בשטח טרם בוצעו. האתר משתמש בגופני מערכת ללא טעינת גופנים מספק חיצוני.

תוצאות בדיקה ומגבלות מפורטות ב־[VALIDATION](docs/VALIDATION.md). אין לבחור רישיון קוד פתוח או להפעיל שירות בתשלום בלי החלטת בעל הפרויקט.

## חיבור נתונים חי — ניסוי מקומי

Google Places Nearby Search מחזיר עד 20 מקומות לפי מרחק; סינון פתוחות מתבצע על הקבוצה שהוחזרה, ולכן אין הבטחה לכיסוי כל המסעדות ברדיוס. אימות נוסף דרך Place Details לפני הגרלה. מצב unknown אינו פתוח. מחיר חסר לא מנוחש. האיורים אינם תמונות המסעדות.

מגבלה מקומית: 20 קריאות ספק בדקה ועד 100 לתהליך, כולל אימותי הגרלה. המונה מתאפס בהפעלת שרת מחדש ואינו תקרת חיוב חודשית או הגנה לפריסה מרובת שרתים. הגדרת מכסות וחיוב ב־Google עדיין נדרשת לפני הפצה. הנתונים אינם נשמרים בדיסק או ב־cache.

ראו [החלטות החיבור](docs/DECISIONS.md).

## התקנה למסך הבית

Manifest, אייקונים 192/512 (כולל maskable) ואייקון Apple מאפשרים פתיחה עצמאית בדפדפנים תומכים. כרטיס התקנה מופיע אחרי בחירת מסעדה או סיום משחק אם הדפדפן מספק בקשת התקנה או מזוהה iPhone/iPad. כפתור קבוע בתחתית האתר פותח הדרכה גם בדפדפן שאינו מספק prompt. דחייה משתיקה הצעות אוטומטיות לשבוע; ההתקנה תמיד אופציונלית.

שני נוסחי הכפתור מוקצים מקומית רק בהסכמה למדידה. ללא הסכמה מוצג הנוסח הרגיל ולא נשמרים ביקורים או מונים. רשומת `munchadoo.install.v1` ב־localStorage מכילה נוסח, זמני ביקור/דחייה ומוני אירועים בלבד, ללא מיקום או מידע על מסעדות. הנתונים אינם נשלחים לשירות מדידה; זו הכנה לניסוי ולא דוח המרה מרכזי. לחיצה, אישור prompt ואירוע התקנה נשמרים בנפרד; ב־iOS אין אימות התקנה מההדרכה, אך פתיחה במצב standalone מזוהה. מחיקת נתוני האתר מאפסת את המדידה ואת הדחייה.

אין הבטחת עבודה ללא רשת או התראות push. לא נוסף cache של מידע מסעדות. שימוש בטלפונים מחוץ למחשב דורש אירוח ב־HTTPS ובדיקות התקנה ב־Safari וב־Chrome בפועל; לא בוצעה פריסה ציבורית.

## פרטיות, מידע ונגישות

נוספו /about, /privacy, /terms ו־/accessibility בעברית ובאנגלית. המפעילה: Clickabily; כתובת פניות: info@clickabily.com. חלונית פרטיות מאפשרת חיוניים בלבד, אישור מדידה מקומית או התאמה אישית; שינוי הבחירה זמין בכל עמוד. מדידה אופציונלית חסומה עד הסכמה. ביטול או תפוגה מסירים נתונים מקומיים בשימוש הבא.

נוספו דילוג לתוכן, תוויות והודעות מצב, טקסט קריא יותר וניגודיות משופרת, הגדלת טקסט וצמצום תנועה. התאמות אלו אינן אישור נגישות מלא. יש להשלים ביקורת נגישות מקצועית ובדיקת מסמכים משפטיים ופרטי מפעילה לפני פרסום. ראו [סקירת יישום ודרישות השקה](docs/PRIVACY-ACCESSIBILITY-REVIEW.md).

## פרסום ל־Namecheap מהמחשב המוגדר

לאחר בקשת פרסום של בעל הפרויקט, מריצים `bash scripts/publish.sh` עם Node 24.
התהליך בודק lint, טיפוסים ובדיקות, בונה בעותק מבודד ללא קובצי סודות,
מעביר את קובצי הריצה ב־SSH, שומר גיבוי ומפעיל מחדש את Passenger.
בדיקת HTTPS וקובץ JavaScript מהבנייה החדשה נדרשת להצלחה; בכישלון בדיקה מתבצע שחזור.
אין העלאה ידנית דרך cPanel ואין פרסום אוטומטי בכל עריכה.

מפתח הפרסום נמצא מחוץ למאגר ב־`work/deploy-access` בתיקיית העבודה של Codex,
עם הרשאות מקומיות מוגבלות. זהו חיבור מהמחשב הזה, לא GitHub Actions.
שינוי dependencies נעצר עד התקנה ובדיקה נפרדת בשרת. מפתח Google נשאר בהגדרות cPanel.
גיבויים נשמרים בשרת תחת `~/munchadoo-releases`; יש לנקות גרסאות ישנות לפי הצורך.
הפרסום מפעיל מחדש תהליך וייתכן ניתוק קצר; אין כאן הבטחת zero-downtime.
